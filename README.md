# GuateGeeks — Simulador Comercial y Financiero

Simulador web para comparar las ofertas INTEGRA, FLEX y EVOLUCIONA de GuateGeeks.

La aplicación permite analizar inversión institucional, precios con y sin IVA, costo por estudiante, margen estimado de GuateGeeks y resultado económico estimado de la institución educativa.

Los campos del escenario se guardan localmente en el navegador para conservar la última configuración utilizada.
